# Exercise muscle references

`free-exercise-muscles.json` contains only IDs, names, primaryMuscles and secondaryMuscles from the public-domain free-exercise-db combined dataset:

- https://github.com/yuhonas/free-exercise-db
- https://raw.githubusercontent.com/yuhonas/free-exercise-db/main/dist/exercises.json
- Retrieved 23 October 2026, 876 records.
- Reduced snapshot SHA-256: `3796f65dc4a01b86008ee44188fe638ef828bfef9fdf232e083e7f158051d830`.
- Original licence retained as `free-exercise-db.LICENSE.md`.

No images or proprietary technique descriptions from ExRx were copied. ExRx was consulted to check target/synergist distinctions; the independent grouping rules cite family references and show their estimated status in the app. These are not precise measurements of activation. See `docs/MUSCLE_HEATMAP.md` for methodology and exceptions.
